# MODALITY_ASSERTION_SCOPE_REPRESENTATION v1

Baseline 40f21f1. Additive diagnostic production API only; no automatic runtime consumer. Earliest boundary is the original individual intervention record, before name+description+otherNames are concatenated into a scalar modality. Caller supplies exact candidate ID, source names/aliases, raw description and artifact/field linkage. Synthetic controls have explicit fixture provenance. Never reverse-engineer original source from a legacy fact.

## Frozen population and rules

All 21 prior text controls retain their focus-scope expectations. Add twelve structural ambiguity controls (negation, modal possibility, other subjects, coordination, new sentence, cytotoxic payload, repeated peptide at different levels, separators, vector component, comparison, without and semicolon boundary). Their exact expectations are controls.json. Preserve all 23 H19 rows and link every saved modality fact in those rows to coexisting diagnostic assertions or explicit unavailable provenance. Existing 105 modality/gate/qualification controls remain unchanged.

Representation uses raw-coordinate spans, nullable ontology modality (an unresolved constituent noun is not a new modality alias), candidate/product source binding, source SHA/record/field, raw text, typed scope and relations, rule/version, explicit ambiguity, stable content-derived ID and legacy-fact associations. No fact constructor/gate/qualification import or production consumer. All assertions remain diagnostic. Existing fact models and serialization unchanged.

Closed grammar, frozen before code:
1. Mentions use existing ontology modality aliases with literal case-insensitive matching; spaces/hyphen/underscore separators may match interchangeably with exact raw offsets preserved. Legacy substring matches remain visible but cannot establish a semantic mention merely through substring membership.
2. A lexical token is bounded at both ends, except peptide inside the morphological family di/tri/tetra/penta/hexa/hepta/octa/nona/deca/oligo/poly-peptide (optional separator). These are numerical/polymer composition prefixes, not asset aliases. Unrecognized embedded tokens remain AMBIGUOUS (including trap inside tetrapeptide).
3. Source-provided product names must explicitly anchor the start of the same sentence. A structured field alone does not certify the subject of every sentence. Exact case-insensitive alias match, no inferred identity. Sentence terminators period/semicolon/newline prevent carry-forward. No cross-sentence inference.
4. Explicit subject + is a/an + modality at the start of the predicate establishes PRODUCT_LEVEL, unless a following explicit conjugation/composition relation makes that noun a composite constituent. No broad word window or longest-term winner.
5. Component heads: linker, payload, binding domain, domain, vector, component. A modality directly modifies a head (optional -derived and binding); peptide morphology above permitted. Parent binding additionally requires the anchored product sentence to state contains/carries, or a product predicate followed by with/containing/comprised of/delivered using. These phrases express possession/composition, not product modality. Within an explicit comprised-of relation, modality-bearing constituent names are COMPONENT_LEVEL; legacy invalid substrings remain ambiguous. Exact component and relation spans retained.
6. Explicit product predicate followed by conjugated to a constituent is COMPOSITE_RELATIONAL for its modality mentions. It does not certify the ontology composite class selected by an overlapping alias. Retain every matching mention separately; do not collapse.
7. Raw constituent expressions viral vector, radionuclide, cytotoxic may be retained with modality=null and unresolved identity; this adds no ontology aliases. Apply the same source/subject/component relation requirements. A vector delivery phrase is a component relation, not a new virus-therapy assertion.
8. Negation/uncertainty cues not/no/without/may/might/could in the same anchored sentence fail closed to AMBIGUOUS. Coordinated subjects, comparison, unbound subject, bare lists, assay context and unsupported grammar remain ambiguous. No LLM/dependency engine/general NLP classifier.

No source hierarchy change or semantic gate rule. The closed grammar is intentionally incomplete; unsupported text is ambiguous. Frozen rules must not be extended after evaluation to rescue cases.
