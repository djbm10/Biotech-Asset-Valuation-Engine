# Amendment 4: the temporal marker separates the agent from the support term

Status: **FROZEN**, 2026-09-27. Written after a pre-measurement sanity check on the defect
protocols and before any replay. It amends Amendment 2, rule 3 (agent vs reference point), only.

## Why

Amendment 2 defined the reference point as a name *preceded* by a temporal marker. That drops
the original rule's exception ("a support term preceded by 'following' or 'after' does not
count"). Breyanzi (NCT03642626) is withheld as a support agent because of it. Its description
reads "Infuse BREYANZI 2 to 7 days after completion of lymphodepleting chemotherapy". The
product comes first, and the marker sits between it and the support term.

## Change

The agent test depends on what made the clause a support clause:

- **Support-term clause.** A name is the agent unless a temporal marker lies **between** the name
  and the nearest support term in the clause. The order does not matter.
  - "conditioning … before CD19-UCART": the marker lies between them, so CD19-UCART is the
    reference point.
  - "BREYANZI … after … lymphodepleting": the marker lies between them, so Breyanzi is the
    reference point.
  - "lymphodepletion with fludarabine": nothing lies between them, so fludarabine is the agent.
- **"Prior to / before" + product clause** (a clause with no support term): a name is the agent
  only if it occurs **before** the "prior to" or "before".
  - "Cyclophosphamide … prior to CAR-T infusion": cyclophosphamide is the agent.
  - "before CD19-UCART injection": CD19-UCART is not the agent.

The temporal markers, the clause split, the support terms and everything else are unchanged.
